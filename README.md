# WanderLust

WanderLust is a full-stack travel booking web application that allows users to list and book travel stays. It’s inspired by Airbnb and built with a clean, responsive interface and robust backend functionality.

---

## Key Features

- User authentication (signup / login)  
- Hosts can add, edit, and delete property listings  
- Users can browse listings with images and details  
- Feedback system: users can rate (1–5 stars) and comment on stays  
- Users can update or delete their feedback  
- Admin dashboard to manage listings  
- Responsive UI for desktop and mobile  
- MongoDB database for storing users, listings, sessions, and reviews  

---

## Technology Stack

- **Frontend:** HTML, CSS, Bootstrap, EJS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Authentication:** Passport.js
